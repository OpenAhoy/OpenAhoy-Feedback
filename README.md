# OpenAhoy Feedback

This is the public issue tracker for OpenAhoy. Anyone with a GitHub account may submit a bug report or feature request. Access to the private source and distribution repositories is not required.

## 报告问题

请说明 OpenAhoy 版本、操作系统、涉及的平台、复现步骤、预期和实际结果。使用插件内的反馈预览时，请在发送前检查脱敏后的最终内容。

**不要上传** AppSecret、token、cookie、密码、验证码、账号 ID、完整绝对路径、文章正文、私有图片、原始响应或原始日志。截图也请先检查。

本仓库只用于通用使用反馈，不存放产品源码、安装包、文章、账号配置或个人素材。反馈内容公开可见。请勿在 Issue 中提交私密信息或要求访问其他用户的数据。

## 安全与处理范围

GitHub 登录由 GitHub 官方页面处理。维护者会核对和复现反馈；提出问题不保证修复日期，也不会自动触发软件发布、账号操作或文章发表。
